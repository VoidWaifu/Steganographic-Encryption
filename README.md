# Стеганографическое шифрование 🔐

**Скрывайте секретные сообщения внутри обычного текста.**

[Открыть приложение](https://voidwaifu.github.io/Steganographic-Encryption/)

## Что это?

Браузерный инструмент для **стеганографии** — скрытия секретных сообщений внутри обычного текста. Зашифрованное сообщение становится невидимым для посторонних глаз.

## Как это работает?

1. Вводите секретный текст
2. Вводите обычный текст-маскировку
3. Задаёте пароль
4. Получаете текст, который выглядит обычно, но содержит скрытое сообщение

Только человек с правильным паролем сможет извлечь секретное сообщение.

## Особенности

- 🔒 **AES-256** — военное шифрование
- 🎭 **Невидимые символы Unicode** — сообщение невозможно обнаружить визуально
- 🖥️ **100% локально** — данные не покидают браузер
- 🔑 **PBKDF2** — 100 000 итераций для защиты пароля
- 🌍 **Русский и английский** — поддержка обоих языков

## Пример использования

**Обычный текст:**
```
Привет! Как дела? Давно не виделись.
```

**После шифрования** (выглядит так же, но содержит скрытое сообщение):
```
Привет! Как дела? Давно не виделись.
```

## Технологии

- **Web Crypto API** — криптография в браузере
- **AES-GCM** — симметричное шифрование
- **Unicode Zero-Width Characters** — невидимые символы
- **Чистый JavaScript** — без серверов и зависимостей

## ⚠️ Важно

**Запомните пароль!** Без него невозможно восстановить скрытое сообщение.
